# 玉米是什么

**玉米（CORN，Common Resource Negotiator）** 是一款简易的通用资源管理系统。

它通过「**预算 → 配额 → 消耗记录**」的主轴，帮助你在任意活动（学习、工作、项目、生活目标）中对时间、人力、资金等成本进行**计划、分配与追踪**。

## 解决什么问题

- 想知道某个活动的资源还剩多少？
- 想把一笔预算按层级分配给多个子活动？
- 想让资源消耗自动按规则记录，而不是手动填报？

玉米把以上需求收敛到一个统一的领域模型里。

## 设计目标

- **统一逻辑内核**：业务逻辑集中在一个可复用 crate 中，三种部署形态共享。
- **契约驱动**：以 OpenAPI 3.1 规范作为前后端契约。
- **多端入口**：React 系全栈，Web/移动/桌面/本地独立运行。
- **多部署形态**：SaaS 多租户、私有化、本地独立运行。
